# Supabase grátis: o que saber

## Pausa por inatividade
O plano grátis **pausa o projeto após 7 dias sem atividade**. Com usuários reais usando o app isso não acontece. Antes do lançamento, enquanto ninguém usa:
- abra o app uma vez por semana (basta entrar), ou
- se pausar, restaure pelo painel do Supabase (botão **Restore project**) ou pelo conector. Os dados são mantidos.

## Limites do plano grátis
- Banco de dados: **500 MB**.
- Até **2 projetos ativos** na conta.
- Sem backup automático diário: veja abaixo.

## Backup
O FARO é *local-first*: cada motorista guarda os dados no próprio aparelho e o servidor é cópia. Isso já protege contra perda. Como reforço, use a **exportação** do app periodicamente e, no painel do Supabase, exporte o banco (Database → Backups/Dump) de vez em quando.

## Quando migrar para o Pro (US$ 25/mês)
Migre quando houver risco real sem backup diário/pausa, ou o banco chegar perto de 400 MB. A conta fecha com **14 assinantes pagantes** ou mais (14 x R$ 22,99 cobrem os US$ 25 com folga). Antes disso, fique no grátis.
