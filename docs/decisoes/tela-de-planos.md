# Decisões — tela Plano (F8, 2026-10-20)

Branch `claude/tela-de-planos`. Mockup aprovado: tela 6 de `docs/design/mockups-v3-aprovado.html`.

1. **Módulo novo `faro-plans.js`** (regras puras + interface). `faro-account.js` só busca os fatos (sessão, `faro_my_trial_ends_at`, `faro_subscriptions`) e chama `FaroPlans.update`. IDs antigos (`faroSubscriptionTitle/Text/Action`) mantidos para não quebrar contratos.
2. **Estados**: sem conta/anônimo → "Testar 7 dias grátis" abre o cadastro; trial → "Faltam X dias"; ≤2 dias → aviso; trial vencido → "Exportar meus dados" + "Assinar"; assinante (`active/trialing/past_due` com período vigente) → "Gerenciar assinatura" (`abrir-portal-faro`). Conta sem trial registrado (anterior à migration) → oferece assinar, **sem travar**. Revisável.
3. **`billingEnabled=false` (continua)**: botão de cobrança "Em breve" desabilitado; criar conta continua livre. O **modo leitura** (`html[data-faro-read-only="on"]` + evento `faro:plan-state`) só liga com a cobrança ligada e trial vencido. Bloquear "Salvar dia" de fato cabe aos módulos de registro (fora deste escopo): eles devem ler esse atributo/evento. Pendente.
4. **Cupom digitado, nunca por link** (o parâmetro some ao instalar o PWA). "Tenho um código" guarda o código só no aparelho (`faro-promo-code-v1`) e mostra a instrução "Adicionar código promocional" do checkout (que já tem `allow_promotion_codes`). PRAGAS mostra R$ 14,90 por 5 meses e economia R$ 40,45. O servidor não recebe o código (não mudamos a função).
5. **Código de 6 dígitos no iPhone**: o cliente atual (`supabase-js 2.112.3`) suporta `auth.verifyOtp({ email, token, type: 'signup' })`. O que falta é **configuração do Auth** (não alterada aqui): o modelo do e-mail "Confirm signup" precisa conter `{{ .Token }}` (hoje só tem o link). Plano: (a) dono troca o modelo no painel do Supabase; (b) fatia seguinte adiciona no cadastro um campo "Código do e-mail" (6 dígitos, `inputmode="numeric"`, `autocomplete="one-time-code"`) que chama `verifyOtp`, mantendo o link como alternativa. Assim a confirmação acontece dentro do app instalado.
