# CalculaAê — índice de planos

**Atualizado em:** 2026-08-03  
**Plano ativo:** `01-CONSOLIDACAO-DA-EXPERIENCIA.md`

## Regra de uso

Este diretório contém os planos operacionais atuais do CalculaAê.

- Somente um plano pode ficar marcado como **ATIVO**.
- Cada plano deve tratar uma etapa completa e observável do produto.
- Um plano concluído permanece disponível como registro.
- Ideias futuras não entram no plano ativo antes de sua etapa.
- Alterações no aplicativo continuam dependendo de contrato e autorização próprios.

## Documento anterior

O arquivo [`docs/PLANO-DE-APLICACAO.md`](../PLANO-DE-APLICACAO.md) é um **documento histórico**.

Ele preserva ideias, pesquisas e possibilidades anteriores, mas **não é mais o roteiro oficial nem define a prioridade atual**. Qualquer ideia dele só volta ao trabalho quando for escolhida expressamente para um novo plano de etapa.

## Estados permitidos

- **ATIVO:** plano que orienta o trabalho atual.
- **Aguardando:** etapa futura já identificada, ainda sem execução.
- **Congelado:** não deve receber implementação agora.
- **Concluído:** objetivo e critérios de aceite foram comprovados.
- **Arquivado:** preservado apenas como histórico.

## Estrutura obrigatória de cada plano

Cada plano deve informar:

1. objetivo observável;
2. escopo;
3. o que não pode mudar;
4. blocos de execução;
5. riscos;
6. testes;
7. validação no celular;
8. critério de conclusão;
9. estado atual;
10. próximo passo único.
