# VETTA

VETTA é um PWA local-first para organização financeira de motoristas de aplicativo.

## Estado desta base

Esta base começa deliberadamente sem código do aplicativo. As regras de trabalho, os contratos e as verificações vêm antes da primeira mudança de produto, para evitar mudanças confusas e publicação acidental.

O primeiro recorte de produto será definido por contrato e só começará após autorização explícita.

## Leitura obrigatória

1. [AGENTS.md](AGENTS.md) — regras obrigatórias para qualquer pessoa ou agente que trabalhe aqui.
2. [PROJECT_STATE.md](PROJECT_STATE.md) — retrato oficial atual e próxima ação permitida.
3. [docs/CONTRACT_TEMPLATE.md](docs/CONTRACT_TEMPLATE.md) — contrato obrigatório antes de mudar o produto.

## Fluxo resumido

branch de trabalho → site de validação → aprovação do proprietário → `main` → tag estável.

O projeto terá no máximo quatro branches remotas ativas. Seus papéis serão registrados no `PROJECT_STATE.md` quando forem criadas.

Não há publicação configurada nesta base inicial.
