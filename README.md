# Faro

App do motorista de aplicativo (Uber, 99, inDrive): mostra o **lucro real** do dia, da semana e do mês, depois de combustível, contas e metas.

- **Só funciona instalado** (PWA na tela inicial); no navegador comum, mostra como instalar.
- **7 dias grátis**, depois **R$ 22,99/mês**. Cupom `RATAO`: R$ 8,00 de desconto por 5 meses.
- Dados no aparelho, com cópia na nuvem (Supabase) para trocar de celular sem perder nada.

## Comandos
```
npm ci            # instala
npm run check     # todos os testes (node --test tests/*.test.mjs)
npm run build     # gera _site/ (o que vai ao ar)
```
