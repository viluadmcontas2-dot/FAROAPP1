# Branches

- Trabalho em `claude/<nome-humano-em-portugues>`; hoje `claude/faro-2-0-beta-pago`. Nada de hash no nome.
- Reaproveite a branch da sessão; só crie outra se for necessário.
- `git push` normal é livre nas branches `claude/*`. Force-push e apagar branch só com ok do dono.
- Mudança chega ao `main` por pull request com `npm run check` e `npm run build` verdes.
